VS Code's Seti file icon theme, copied by gen-seti.mjs from VS Code's built-in theme-seti extension
(https://github.com/microsoft/vscode/tree/main/extensions/theme-seti): seti.woff, and file-icons.json, which holds its
vs-seti-icon-theme.json mapping and the file associations of VS Code's built-in languages. The source version is in
file-icons.json's "source".

The theme's icons come from Seti UI (https://github.com/jesseweed/seti-ui). Both are under the MIT License.
